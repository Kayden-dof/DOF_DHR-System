# DHR 화면 디자인 점검 (2026-11-06)

대상: `main` b649fd0 (운영과 같은 판). 로컬 개발 서버에 시연 자료(seed:demo · seed:flow)를 넣고 화면 48장을 찍어 보았다.
찍은 화면과 화면별 수치는 세션 공유 폴더 `dhr-design-review/before/` 에 있다 (`report.json` 이 수치).

재는 법

- 1440×900 (사무), 1024×768 (현장 패드), 390×844 (휴대폰) 세 폭.
- 계정: 시스템관리자 · 작업자 · 경영열람 · 품질책임자.
- 화면마다 글자 크기 분포, 글자와 바탕의 대비(WCAG AA 4.5:1), 누름 크기(사무 32px · 현장 48px 미만을 셈), 가로 넘침, 이름표 없는 입력칸, 제목 단계를 스크립트로 셌다.
- 키보드: Tab 으로 초점을 옮겨 초점 테두리가 서는지 보았다.

## 잘 되어 있어 그대로 둘 것

- 초점 테두리(두 겹 링)가 모든 조작 요소에 선다. 움직임 줄이기 설정을 따른다.
- 번호·수량은 고정폭 숫자, 한글은 낱말 단위 줄바꿈. 로트번호가 두 줄로 갈리지 않는다.
- 사무(흰 면)와 현장(어두운 보라 면)이 한눈에 갈린다.
- 빈 화면 문구가 다음 할 일을 말한다 ("아직 제조번호가 붙지 않았습니다. 현장에서 재단 공정을 적으면 형명별로 붙습니다").
- 이름표 없는 입력칸은 거의 없다 (자재 증감 화면 8칸이 예외, 아래 M10).

## 회사 디자인 시스템과의 관계

`Downloads/dof-design-system` 은 흰 종이 · 먹과 회색 위계 · 퍼플은 포인트 · 맑은 고딕을 정본으로 둔다. 이 앱은

- 색 값은 이미 그 정본에서 가져왔다 (바탕 `#F2F0EF`, 구분선 `#E4E0E6`, 상태 색).
- 글자 단계는 정본과 다르다 (M1).
- 머리줄은 정본(흰 면 + 웜그레이 띠)과 달리 어두운 보라다. 2026-09-11 사용자 결정으로 바꾼 것이다.
- 글꼴은 Pretendard 가 먼저고 맑은 고딕이 받침이다. 화면용으로는 Pretendard 가 낫다.
